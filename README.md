# 3Z Shop

3Z Shop is an online storefront for discovering products, exploring their available options, and managing a shopping cart. The storefront is built with Next.js and React and connects to a separate Laravel API.

## Preview

Visitors land on a product-focused storefront and can browse the catalog, narrow results with filters, and open product pages to view images, details, and configurable choices. They can build a cart as a guest or sign in to access account features and API-backed cart and order experiences. The interface also includes profile and administration areas.

## Features

- Browse products, categories, and product details.
- Filter and sort products by category, color, size, price, and rating.
- Explore product images and configurable choices, including price and quantity.
- Register, sign in, and view or update buyer profile information.
- Keep a guest cart in browser storage and use API-backed cart features when signed in.
- Access checkout and order pages.
- Switch between light and dark appearance.
- Include administration screens for catalog, user, and order management.

## Related project

The storefront relies on the [3Z Shop API](https://github.com/Zakaria-ocd/gestion_ecom) for catalog, account, cart, and order data. See the [backend README](https://github.com/Zakaria-ocd/gestion_ecom#readme) for its role and features.
